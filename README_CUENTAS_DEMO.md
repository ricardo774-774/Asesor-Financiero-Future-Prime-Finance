## 🔧 **Comandos de Gestión**

### 📥 **Generar Datos Demo**
```bash
# Ejecutar un perfil específico
php artisan db:seed --class=MaxCruzDemoSeeder
php artisan db:seed --class=AbrahamRamirezDemoSeeder
php artisan db:seed --class=AlexCasillasDemoSeeder

# Ejecutar todos los seeders (incluye los 3 perfiles)
php artisan db:seed

# Regenerar completamente la base de datos
php artisan migrate:fresh --seed
```

### 🧹 **Optimización del Sistema**
```bash
php artisan config:clear
php artisan cache:clear
php artisan view:clear
php artisan optimize
```
